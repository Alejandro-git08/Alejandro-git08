## 🚀 Proyectos destacados

### 📦 [LogiStock](https://github.com/Alejandro-git08/LogiStock)

Sistema de inventario y logística desarrollado como proyecto personal para aplicar conocimientos de ingeniería de software y desarrollo de aplicaciones.

- **Tecnologías:** Java, Spring Boot, PostgreSQL y Maven.
- **Enfoque:** gestión de inventario, productos, almacenes y movimientos.
- **Objetivo:** desarrollar una solución que permita organizar y gestionar operaciones relacionadas con el inventario.

🔗 [Ver repositorio](https://github.com/Alejandro-git08/LogiStock)

### 📱 [Alacena Digital](https://github.com/Alejandro-git08/Alacena-Digital-m-vil)

Aplicación móvil para gestionar información de una alacena, desarrollada como proyecto académico utilizando herramientas de desarrollo Android.

- **Tecnologías:** Java, Android Studio, XML y Room.
- **Enfoque:** desarrollo de aplicaciones móviles, interfaces de usuario y persistencia local de datos.
- **Objetivo:** aplicar conocimientos de programación y almacenamiento de información en una aplicación Android.

🔗 [Ver repositorio](https://github.com/Alejandro-git08/Alacena-Digital-m-vil)
